# Changelog

## 1.1.0

- Kept the application fully native C++17 / Win32.
- Added Turkish and English UI with persistent language selection.
- Reworked the interface into a dark card-based layout.
- Added a responsive resizable window and Windows 10/11 dark title bar.
- Added an original database-to-SQL application icon and EXE resources.
- Added drag & drop folder selection.
- Added background processing so the UI stays responsive.
- Added a custom double-buffered progress bar with percentage and stage text.
- Added Save As actions for SQL and report files.
- Added Open Output Folder and optional auto-open on success.
- Added Copy Log and Clear Log actions.
- Added remembered last source folder.
- Added DPI-aware manifest, Visual Studio solution, CMake build, and GitHub Actions workflow.
